# Technology Stack (Free & Best)

To build a robust, scalable, and intelligent AI-Powered Career Readiness & Employability Platform with zero budget during the hackathon, we will use the absolute best free-tier and open-source tools available.

## Frontend (The User Interface)
- **Framework:** **Next.js (React)** - The industry standard. Provides blazing-fast performance and seamless API route integration. (100% Free / Open Source)
- **Styling:** **Tailwind CSS** + **shadcn/ui** - For beautiful, accessible, premium-looking components that you can copy-paste and customize. (100% Free / Open Source)
- **Icons:** **Lucide React** - Clean, modern icons. (Free)

## Database, Auth & Backend (The Engine)
- **Backend-as-a-Service:** **Supabase** - The best open-source Firebase alternative. Their generous free tier gives you:
  - **Database:** Full PostgreSQL database.
  - **Auth:** Ready-to-use user authentication (email, Google, etc.).
  - **Storage:** Blob storage for resume PDFs and profile pictures.
  - **AI Search:** Native `pgvector` support for matching resumes to jobs using AI embeddings!

## AI & Machine Learning (The Brains)
- **Generative AI:** **Google Gemini API** (via Google AI Studio) - Offers an incredible free tier for developers. Perfect for resume parsing, mock interviews, and career recommendations.
- **Fast Open-Source AI (Optional):** **Groq API** - Provides lightning-fast, free API access to open-source models like Llama 3 (great for fast text classification or secondary AI tasks).

## Deployment & Hosting (Going Live)
- **Application Hosting:** **Vercel** - The creators of Next.js. Their Hobby Tier is 100% free, auto-deploys from GitHub, and hosts both your frontend and API routes flawlessly.
- **Code Repository:** **GitHub** - For version control and collaboration. (Free)
